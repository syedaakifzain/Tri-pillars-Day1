☕ Tri-Pillars — Day 1 Java Practice

A collection of Java programs created as part of my Tri-Pillars Java learning journey. This repository focuses on building strong programming fundamentals through hands-on practice and problem-solving.

📌 About

Day 1 focuses on understanding the basics of Java by implementing small programs independently. The goal is to strengthen logical thinking, understand Java syntax, and become comfortable writing and testing Java programs.

The repository contains programs covering:

Conditional statements
Loops
Number manipulation
Pattern programming
Type conversion
Switch expressions
Basic problem-solving
