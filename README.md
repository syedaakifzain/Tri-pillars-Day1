Tri-Pillars — Day 1 Java Practice

I created this repository as part of my Java learning journey, focusing on strengthening my programming fundamentals through hands-on practice. During Day 1, I worked on small Java programs covering basic concepts such as conditional statements, loops, number manipulation, pattern programming, type conversion, and switch expressions.

I implemented individual programs for problems such as Armstrong numbers, palindrome checking, happy numbers, even/odd identification, reversing digits, swapping values, and different pattern-printing exercises. I also explored concepts such as implicit and explicit type conversion along with modern Java switch/yield functionality.

The main goal of this practice was to build a stronger foundation in Java by writing and testing each concept independently rather than only learning the theory.
